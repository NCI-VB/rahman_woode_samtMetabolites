This repo contains the raw data and code used to produce the figures in the manuscript

## Friend or foe: divergent immunomodulatory effects of metabolites derived from the virucidal zinc finger inhibitor SAMT-247
Woode et al. 2026 Frontiers in Immunology 

- raw datasets used can be found in input_data/ccbr1472_SAMTderivatives_KCG_list_of_RAWdatasets.xlsx

- data plotted in each figure panel can be found in outputs/ccbr1472_SAMTderivatives_KCG_ForMS_list_of_plotted.xlsx

- statistical analysis results can be found in outputs/ccbr1472_SAMTderivatives_KCG_ForMS_list_of_stats.xlsx

- all code can be found in ccbr1472_SAMTderivatives_Arif_ForMS_KCG.Rmd

- the fully rendered report with a tab for each figure panel can be found in outputs/ccbr1472_SAMTderivatives_Arif_ForMS_KCG.html
